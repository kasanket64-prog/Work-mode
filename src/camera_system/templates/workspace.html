Command Line & Docker Quickstart

Copy and run commands from the repository root (`Work-mode/`).

Local Workspace Server
.venv\Scripts\camera-workspace.exe --port 8780 --warm-worker --strict-uploads
Kalman + Live RTSP Stream CLI
.venv\Scripts\camera-video.exe --stream rtsp://cam.local/live --stream-credentials-env CAM_CREDS --live-buffer --reconnect-attempts 3 --tracker kalman --output outputs\stream.jsonl
Calibration Benchmark
.venv\Scripts\camera-benchmark.exe outputs\demo\session.jsonl --truth outputs\demo\truth.json --output-dir outputs\bench
Docker Compose (CPU / GPU)
docker compose up --build

Frequently Asked Questions

How is chain of custody preserved on ingested footage?

Every upload is hashed incrementally with SHA-256 as bytes land on disk, and every ingestion, case update, bookmark, verdict, replay, and report export appends a SHA-256 linked record to the SQLite `audit_log` ledger.

Can I align multiple cameras whose DVR clocks are wrong?

Yes. Set a clip's recorded UTC start timestamp and positive/negative DVR clock offset (in seconds) during intake or inside the Case Desk. Evidence search and case reports display aligned wall-clock times automatically.

Are AI scores or linked entities treated as legal proof?

No. Detections, predicates, and candidate events remain explicitly separated from human-verified verdicts, pinned frame bookmarks, and investigator entity links. Real-world accuracy requires evaluation on reviewed footage.

Do redactions modify my original evidence file?

Never. Zoom, brightness/contrast enhancement, and bystander redaction boxes are non-destructive canvas layers applied when viewing or exporting still PNG snapshots; original uploaded media remains untouched.

Does it analyze the entire recording?

Videos are sampled at your selected stride up to the frame limit. Inside Review, the original video player also provides `−1f / +1f` frame stepping and variable speed (`0.25×`–`2×`) to inspect moments between sampled frames.
